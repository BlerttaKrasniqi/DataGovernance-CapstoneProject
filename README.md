# DataGovernance-CapstoneProject


## Standardized Metadata Schema

The following metadata fields will be used as the standard schema across the project:

- column_id
- column_name
- column_desc
- term_name
- term_description
- security_classification
- critical_data_element_flag
- pii_flag
- term_subdomain
- data_steward
- table_id
- table_name
- table_desc
- table_owner_in_source
- schema_id
- schema_name
- database_id
- database_name
- system_id
- system_name
- location
- total_record_count
- invalid_record_count
- tag_name
- tag_value
- certification_level
